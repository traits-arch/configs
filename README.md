1.Install Niri First

2.Replace the config.kdl file with the Cloned repo one

3.Install rofi, waybar, swaync & hyprlock.

4.Replace the config & css files one by one.

5.Tinker the configs according to your system otherwise niri will throw errors. (Use LLMs for help if needed)

6.The custom module uses scripts that are set to launch some specific softwares on my system, you can create your own scripts and use the gestures for ease. 

7.The extras folder contains my personal configs for vs code and firefox, i've eliminated the tab and controll bars in both for a sleek look and everything is controlled through keybinds, though there is a hover function to show up options.

8.fastfetch needs a sticker.png file to display which you can replace with the picture of your own choice. 

9.swaync needs some polishing, I'm working on it but a little busy in some work for now.

10.Also rofi powermenu too, need to set it up according to the vibe.

11.waybar icons each have a purpose so i suggest to checkout the modules.json file.

12.Niri contains multiple keybinds, i suggest to study them or customize them to your own use. 

13.If anything breaks, use niri validate to find out the issue. 

14.I've chosen alacritty for its speed and efficiency, you're free to use ghosty or kitty ( also it lets your display graphics in the terminal)
the starship.toml is customizable, everything is. just replace the colours with colours of your own choice.

15.I'll be working on upgrading overall with time, stay tuned.
